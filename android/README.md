# TrueTone Android

Integrated version of Harshini's Jetpack Compose frontend. See ../SUBMISSION.md for setup and demo steps.

- Settings: configure an HTTPS backend origin and test its health.
- Detect: analyze scripted text using real backend responses.
- History: save results for this app session.
- Audio: open the browser microphone page, then fetch the latest backend result.

Preset alternating results were removed. No Twilio secrets belong in the app. This prototype does not intercept cellular calls or detect synthetic voices. Live phone analysis remains unverified.

Open this directory in Android Studio, sync and run.
